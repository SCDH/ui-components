# FacetSearch – Composite Search Interface

The **FacetSearch** component combines `SearchBar`, `Facet`, and `ListItem` into a
complete search interface with faceted filtering. It demonstrates how data flow,
state management, and UI composition work together.

## Interaction Modes

The `FacetSearch` component supports three different interaction modes:

### Instant Mode (Default)
Every facet click immediately triggers a new search.

### Explore Mode
The facet sidebar "freezes" upon selection, allowing users to select multiple items from the same dimension without losing context.

## Usage

```tsx
import { FacetSearch, SearchServiceProvider } from '@scdh_muenster/ui-components'

// 1. Implement the SearchService interface for your backend
class SolrSearchService implements SearchService {
  async search(request: SearchRequest): Promise<SearchResponse> {
    const response = await fetch(`/solr/query?q=${request.query}`)
    return response.json()
  }
}

// 2. Wrap FacetSearch with the provider
function App() {
  const service = useMemo(() => new SolrSearchService(), [])

  return (
    <SearchServiceProvider service={service}>
      <FacetSearch searchPlaceholder="Search the catalogue..." searchAriaLabel="Full-text search" />
    </SearchServiceProvider>
  )
}
```
